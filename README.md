<h1 align="center">Simple Calc</h1>

Simple Calc is a simple calcuator made with Java for Android 7.0 and forward, built to serve basic calculator functionalities.

## Features

- Standard Calculator functionaloity with simple comands as add, divide, substract, multiply and divide.
- Semi-advanced functionalities, such as percentages, parenthesis handling and non integers.
- Complete precision over calculations.
- Lightweight size. It weights less than 1mb (APK size).
